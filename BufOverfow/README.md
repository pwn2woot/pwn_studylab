## 실행 방법

제공된 `bof`는 **Linux x86-64용 실행 파일**입니다. Windows에서는 WSL의 x86-64 Linux 환경을 사용하세요.

저장소 루트에서 문제 폴더로 이동한 뒤, 실행 권한을 부여하고 실행합니다.

```bash
cd BufOverfow
chmod +x bof
./bof
```
