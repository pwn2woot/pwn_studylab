# BufOverfow

버퍼 오버플로를 학습하기 위한 문제 모음입니다.

## 문제 목록

| 번호 | 문제 | 목표 |
|:---:|------|------|
| 01 | [bof — 셸 호출 함수 실행](#01-bof) | 바이너리 내부의 셸 호출 함수 실행 |
| 02 | [password_bof — 비밀번호 변경](#02-password-bof) | 오버플로로 비밀번호를 변경한 뒤 인증해 셸 획득 |

## 실행 방법

제공된 `bof`와 `password_bof`는 **Linux x86-64용 실행 파일**입니다. Windows에서는 WSL의 x86-64 Linux 환경을 사용하세요.

저장소 루트에서 문제 폴더로 이동한 뒤, 실행 권한을 부여합니다.

```bash
cd BufOverfow
chmod +x bof password_bof
```

원하는 문제를 하나씩 실행합니다.

- **1번 문제:** `./bof`
- **2번 문제:** `./password_bof`

<a id="01-bof"></a>

## 01. bof — 셸 호출 함수 실행

**제공 파일:** [bof](bof)

바이너리 안에 **셸을 호출하는 함수**가 존재합니다.

프로그램을 분석하고, 해당 함수를 호출해 **셸이 실행되도록 하는 것**이 목표입니다.

<a id="02-password-bof"></a>

## 02. password_bof — 비밀번호 변경

**제공 파일:** [password_bof](password_bof)

버퍼 오버플로를 이용해 **프로그램 내부의 비밀번호 값을 변경**하는 문제입니다.

비밀번호를 변경한 뒤, **변경한 비밀번호를 입력해 셸을 얻는 것**이 목표입니다.
