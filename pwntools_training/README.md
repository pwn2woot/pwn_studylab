# Pwntools Training

Pwntools로 프로그램의 표준 입력과 출력을 다루는 연습 문제 모음입니다. 메뉴 조작, 64비트 정수의 바이트 변환, 반복되는 계산 문제를 순서대로 연습합니다. 각 문제의 조건을 만족하면 FLAG가 출력됩니다.

## 문제 목록

| 문제 | 주제 | 제한 시간 | 주요 연습 내용 |
|------|------|-----------|----------------|
| [01_menu](#01-menu) | 랜덤 비밀번호 입력 | 비밀번호 제출 1초 | 메뉴 자동화, 비밀번호 추출, `sendlineafter()` |
| [02_pack64](#02-pack64) | 64비트 정수 전송 | 없음 | 리틀 엔디언, `int(..., 16)`, `p64()`, `sendafter()` |
| [03_rounds](#03-rounds) | 3초 덧셈 계산기 | 10라운드 전체 3초 | 숫자 추출, `str(...)`, 반복문, `sendline()` |
| [maze_golf](#04-maze-golf) | Maze Golf — 최단 코드 미로 탈출 | 게임 30초 | `process()`, `send()`, 파일 바이트 수 최적화 |

## 실행 방법

제공 파일은 **Linux x86-64용 실행 파일**입니다. Windows에서는 WSL의 x86-64 Linux 환경에서 실행할 수 있습니다.

저장소 루트에서 문제 폴더로 이동한 뒤 실행 권한을 부여합니다.

```bash
cd pwntools_training
chmod +x 01_menu 02_pack64 03_rounds maze_golf Score
```

원하는 문제를 하나씩 실행합니다.

```bash
./01_menu
./02_pack64
./03_rounds
./maze_golf
```

자동화 스크립트를 작성할 때는 해당 Python 환경에 Pwntools가 설치되어 있어야 합니다.

<a id="01-menu"></a>

## 01_menu — 랜덤 비밀번호 입력

실행할 때마다 **16자리 숫자 비밀번호**가 새로 생성됩니다. 이름을 입력한 뒤, 메뉴에서 비밀번호를 확인하고 제출합니다.

```text
1) Read hint
2) Submit password
3) Quit
choice>
```

1. 이름을 입력합니다.
2. 메뉴에서 **1번**을 선택해 비밀번호를 확인합니다.
3. 메뉴에서 **2번**을 선택하고, `password> ` 프롬프트에 비밀번호를 제출합니다.

**2번을 선택한 뒤 1초 안에 비밀번호와 줄바꿈까지 입력해야 합니다.** 이름 입력과 메뉴 선택에는 시간 제한이 없습니다.

- 정답을 제출하면 FLAG가 출력됩니다.
- 시간 안에 오답을 제출하면 메뉴로 돌아갑니다.
- 제한 시간을 초과하면 프로그램이 종료됩니다.

**연습 내용:** 메뉴 자동화, 출력에서 비밀번호 추출, `sendlineafter()`로 프롬프트를 기다린 뒤 줄바꿈을 포함한 입력 전송.

<a id="02-pack64"></a>

## 02_pack64 — 64비트 정수 전송

프로그램이 출력한 정수를 **리틀 엔디언 형식의 8바이트**로 변환해 제출합니다.

출력 예시:

```text
value = 0x8877665544332211
bytes>
```

위 예시에서 전송해야 하는 8바이트를 16진수로 표시하면 다음과 같습니다.

```text
11 22 33 44 55 66 77 88
```

위 내용을 문자로 입력하는 것이 아니라, 해당 값을 가진 **바이너리 바이트 8개**를 전송해야 합니다. 리틀 엔디언은 정수의 가장 낮은 자릿값에 해당하는 바이트부터 배치하는 방식입니다.

1. 출력에서 16진수 숫자 문자열을 읽습니다.
2. `int(읽은값, 16)`으로 문자열을 정수로 변환합니다.
3. `p64()`로 정수를 리틀 엔디언 8바이트로 변환합니다.
4. `bytes> ` 프롬프트에 **추가 줄바꿈 없이** 전송합니다.

- 정답이면 FLAG가 출력되고, 오답이면 프로그램이 종료됩니다.
- 시간 제한은 없습니다.
- 8바이트보다 적게 보내면 프로그램은 나머지 입력을 기다립니다.

**연습 내용:** 문자열과 정수의 차이, 리틀 엔디언, `p64()`, `sendafter()`로 줄바꿈을 추가하지 않고 바이트 전송.

<a id="03-rounds"></a>

## 03_rounds — 3초 덧셈 계산기

**0~9 사이의 랜덤 숫자 두 개를 더하는 문제**가 총 10라운드 출제됩니다.

출력 예시:

```text
ROUND 1/10
3 + 5 =
```

위 예시에서는 `8`과 줄바꿈을 제출합니다. 정답의 범위는 **0~18**이며, 계산한 정수를 **숫자 문자열**로 변환해 보냅니다.

**시작 후 3초 안에 전체 10라운드를 완료해야 합니다.** 라운드가 바뀌어도 제한 시간은 초기화되지 않습니다.

- 정답이면 다음 라운드로 진행합니다.
- 오답을 제출하거나 제한 시간을 초과하면 프로그램이 종료됩니다.
- 10라운드를 모두 맞히면 FLAG가 출력됩니다.

**연습 내용:** 출력에서 숫자 추출, 덧셈, `str(...)`로 정수를 문자열로 변환, 반복문과 `sendline()`으로 답 전송.

## 04. Maze Golf — 최단 코드 미로 탈출

**제공 파일:** [maze_golf](maze_golf) · [Score](Score)

고정된 미로에서 `@` 캐릭터를 움직여 `E` 출구에 도착하는 문제입니다.

```text
@ : 플레이어
E : 출구
# : 벽
. : 이동 가능한 길
```

조작 키는 `W`, `A`, `S`, `D`이며 대소문자를 모두 지원합니다. 터미널에서 직접 실행하면 키를 누르는 즉시 캐릭터가 움직이고, 30초 안에 출구에 도착하면 FLAG가 출력됩니다.

이 문제의 최종 목표는 미로를 푸는 것뿐 아니라, 정상적으로 탈출하는 **Pwntools 풀이 파일의 실제 바이트 수를 최대한 줄이는 것**입니다. 풀이 파일에서는 이름이 고정된 문제 바이너리를 실행합니다.

```python
from pwn import *

p = process('./maze_golf')
# WASD 경로 전송
```

### 채점

작성한 Python 파일을 `Score`의 첫 번째 인자로 전달합니다. 솔버 파일명은 자유입니다.

```bash
./Score solve.py
./Score test.py
./Score ex.py
```

채점기는 매번 다른 검증 토큰을 사용해 제출 코드를 5번 실행합니다. 5번 모두 실제 미로 탈출 후 동적 FLAG가 출력돼야 점수를 보여줍니다.

```text
[*] Solver: solve.py
[*] File size: 143 bytes
[+] Verification: 5/5
[+] FLAG verified: 5/5
[+] SCORE: 143 bytes
```

점수는 공백, 개행, 주석을 모두 포함한 Python 파일의 실제 크기입니다. Pwntools를 import한 UTF-8 Python 파일이어야 하며 최대 크기는 4096바이트입니다. 점수는 저장하지 않습니다.
